# Sky Fighter 점검 결과 & 로드맵

> **진행 상황**: Phase 0~2 완료 + 파일럿 선택/전용 궁극기, 런 모디파이어, 무한 모드, 미사일 타격감, 패럴랙스까지 구현. 배포: https://yano7788-star.github.io/sky-fighter/ (main 푸시 시 자동). 남은 후보: 융합 확장, 일일 도전, 스테이지 기믹, 보스 3페이즈, 브리핑 컷.


기준: `index.html` (develop 브랜치 시작 시점). 아래 "확인됨"은 코드 정독 또는 브라우저/네트워크로 직접 확인한 항목.

## 1. 점검 결과

### 구조 현황
- `index.html`(1,228줄)이 Pages에서 서비스되는 게임. 스테이지 5개, 보스 5종(2페이즈), 아이템 4종(P/M/E/B), 폭탄, 라이프 2, 터치/마우스 조작, WebAudio 합성 BGM·효과음.
- `Cyber_Strike.html`(2,182줄)은 **기능이 더 많은 별도 계열**: 궁극기(skill1/2.jpg), 동료 CAT/DOG, 중간보스(2·3스테이지), 타격감(셰이크·히트스톱), mp3 BGM(`under_heavy_fire.mp3`), 워쉽 스프라이트 적. `titan_at_the_gate.mp3`는 어디에서도 안 쓰임.
- 둘 다 일시정지·키보드·최고점수·난이도 선택 없음.

## 2. 로드맵

### Phase 0 — 기반 (먼저 해야 이후 작업이 안전)
1. **고정 타임스텝 루프**: `update(dt)`/`render()` 분리, 60Hz 기준 누적기. 이후 모든 로직이 기기와 무관하게 동일 속도.
2. **DPR 대응 + 리사이즈 재보정.**
3. **에셋 최적화**: WebP 변환·리사이즈·투명 사전 처리 (목표 14MB → 1MB 안팎), 로딩 진행 바, 스테이지 배경 지연 로드. (`asset-optimizer`)
4. 파비콘 + PWA manifest + 서비스워커(오프라인 플레이).
5. 코드 정리: 단일 파일 유지가 목표면 `// ====` 섹션 규칙 고수, 보스 패턴을 데이터 테이블로 분리(현재 `if tier` 중첩 80줄 → 선언형).

### Phase 1 — 기본기 (체감이 큰 것)
- 일시정지(버튼·ESC·탭 전환 시 자동), 키보드(WASD/방향키 + Space/B), 게임패드.
- 최고 점수·최고 스테이지 localStorage 저장, 신기록 연출.
- 타격감: 화면 흔들림, 히트스톱, 피격 플래시, 보스 피격 임팩트 링, 총구 섬광 (Cyber_Strike.html 490–540 참고).
- mp3 BGM 도입: 일반/보스 분리(`under_heavy_fire` / `titan_at_the_gate`), 보스 진입 시 크로스페이드, 탭 숨김 시 일시정지, 음소거 상태 저장.
- 모바일 진동(`navigator.vibrate`) 피드백.

### Phase 2 — 콘텐츠
- **적 다양화**: 지그재그·돌진·편대(V자/라인)·저격형·보호막형, 스테이지별 등장 테이블.
- **중간보스**(Cyber_Strike.html 1242–1418 포팅), **궁극기**(skill1/2.jpg 컷인), **동료** CAT(흡혈)/DOG(보호막)(782–1050 포팅). 먼저 `index.html`이 정본인지 결정 필요.
- 점수 시스템: 연속 처치 콤보 배율, 근접 회피(graze) 보너스, 무피격 스테이지 보너스, 스테이지 랭크(S–C).
- 무기: 파워업 레벨 확장·레이저/스프레드 전환, 아이템 자석 효과, 폭탄 종류.
- 보스 패턴: 탄막 시각 텔레그래프(발사 전 경고), 3페이즈 최종 보스, 레이저/돌진 패턴.
- 환경 요소: 스테이지 기믹(2: 전자기 방해 / 3: 운석 지대 실제 충돌 / 4: 용암 기둥 / 5: 중력 왜곡).

### Phase 3 — 확장
- 난이도(Easy/Normal/Hard) 및 무한 모드(엔드리스 + 점점 강해지는 웨이브).
- 일일 도전(날짜 시드 고정 웨이브), 공유용 결과 카드 이미지 생성.
- 업적/해금(기체 스킨·색상 팔레트), 다국어(ko/en).
- 온라인 랭킹은 서버가 필요하므로 보류(정적 Pages 한계).

## 3. 서브에이전트 운용 (.claude/agents/)
| 에이전트 | 역할 | 쓰는 시점 |
|---|---|---|
| `game-qa` | 브라우저·시뮬 하네스로 버그 사냥, 코드 수정 없이 보고 | 기능 추가/수정 직후 |
| `game-balance` | `tools/sim-bot.js` 반복 실행으로 난이도·드랍·HP 튜닝 근거 제시 | 보스/적/아이템 수치 변경 시 |
| `asset-optimizer` | 이미지·사운드 용량 절감과 사전 처리 | Phase 0-3 |

권장 흐름: 구현(메인) → `game-qa`로 검증 → 필요 시 `game-balance`로 수치 조정 → 커밋.
