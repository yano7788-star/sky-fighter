# SKY BREAKER — 게임 디자인

전통 종스크롤 슈팅의 "탄막 회피·보스전"에 최신 게임의 **런 중 성장(로그라이트 빌드)**, **스킬 융합**, **영구 성장**을 섞은 구조.
한 판은 5스테이지 보스 러시(약 5~7분). 판마다 다른 빌드가 나와서 계속 다시 하고 싶어지는 것이 목표.

## 1. 한 판의 흐름
```
스테이지 N:  일반 전투(35~55초) → [중간보스(2·3스테이지)] → WARNING → 보스(2페이즈) → 클리어(랭크 보너스) → 다음
적 처치 → 청록 젬 → 모으면 레벨업 → 카드 3장 중 1장 → 빌드가 커짐 → 보스를 더 빨리, 더 안전하게
```
- 보스 등장은 **점수가 아니라 전투 시간** 기준(콤보/그레이즈로 점수가 부풀어도 스테이지 길이는 일정).
- 레벨업 중에는 게임이 완전히 멈춘다(카드를 천천히 고민할 수 있음).

## 2. 전통 요소 (유지)
| 요소 | 내용 |
|---|---|
| 탄막·보스 | 보스 5종 × 2페이즈, 탄막 패턴은 데이터 테이블(`BOSS_PATTERNS`) |
| 폭탄 | **강화됨**: 화면의 모든 탄 제거(점수화) + 화면의 적 전멸 + 보스 최대체력 12% 즉시 + 폭발장이 퍼지며 지속 피해(+8%) + 1.5초 무적 |
| 목숨/에너지 | 에너지 바 + 목숨 2개(최대 4), 아이템 E/L로 회복 |
| 아이템 | P 파워업(기본 대포 Lv1~5) · M 유도미사일(시간제) · E 에너지 · B 폭탄 · G 자석 · L 목숨 |

## 3. 레거시에서 되살린 것
- **동료 (아이템 C/D)**: 고양이 = 8초간 *흡혈*(준 피해의 20%, 최대 80%까지) + *내 탄이 모두 유도탄*, 강아지 = 8초간 *방어막*(반경 안의 적 탄 제거, 닿는 적 파괴). 스테이지당 각 1회, 처치 수가 쌓일수록 드랍 확률 상승(피티).
- **궁극기 「자매의 손바닥」**: 컷인 카드 → 작은 손바닥들 → 거대한 손바닥이 화면 전체로 낙하 → 모든 탄 제거 + 적/중간보스 최대체력 50%, 보스 30%. 이제 *게이지제*(처치·그레이즈·보스 처치로 충전). 옛 규칙("3번째 보스를 목숨 2개 이상 유지하고 처치")은 **게이지 즉시 만땅 보너스**로 유지.
- **중간보스**: 비명 지르는 얼굴, 입에서 레이저(고정 예고선 1.2초 → 발사). 처치 보상 = 목숨.

## 4. 새로 섞은 최신 트렌드
### 4-1. 런 중 성장 (Vampire Survivors / Brotato 식)
레벨업 카드 풀 — **무기 모듈**(최대 Lv4): 산탄, 관통탄, 유도 미사일, 위성 드론, 관통 레이저 / **패시브**: 연사, 화력, 자력, 장갑(+25 에너지), 전술 분석(+XP), 폭탄 보급, 행운, 자동 방벽(N초마다 피격 1회 방어).
### 4-2. 스킬 융합 (진화)
두 모듈이 모두 **Lv3 이상**이 되면 다음 레벨업에 *금색 FUSION 카드*가 반드시 등장.
| 융합 | 조건 | 효과 |
|---|---|---|
| **스웜 바라지** | 산탄 + 유도 | 보조탄이 적을 추적, 피해 +40% |
| **레일건** | 관통 + 레이저 | 레이저 2.2배 굵기·피해 2배, 기본탄 관통 +2 |
| **헌터 스쿼드** | 유도 + 드론 | 드론이 유도 미사일 발사 |
| **아이기스 오빗** | 드론 Lv2 + 자동 방벽 Lv2 | 드론이 닿는 적 탄을 지움 |
| **프리즘** | 레이저 + 산탄 (Lv3) | 레이저 3줄기 |
| **오버클럭** | 연사 + 화력 (Lv3) | 콤보 5 이상일 때 연사 +35%, 피해 +20% |
→ "빌드를 어디로 끌고 갈지" 선택이 생김. 이미 가진 모듈이 카드로 더 자주 나오도록 가중(한 방향 몰빵의 쾌감).
### 4-3. 영구 성장 — 격납고(HANGAR)
런이 끝나면 `점수/20 + 스테이지×30 (+클리어 300)` 크레딧. 크레딧으로 장갑/탄약/전술 데이터/회수 장비/버스트 코어를 영구 강화. 실패해도 진전이 남는 구조.
### 4-4. 파일럿 (자매)
타이틀의 PILOT에서 선택. **에이스**(기본, 무패시브) / **언니**(연사 +15%, 피해 +10%, 블랙·레드 기체) / **동생**(시작 에너지 +25, 흡수 범위 +30%, 경험치 +10%, 화이트·골드 기체). 언니·동생은 크레딧 400으로 해금.

### 4-5. 런 모디파이어 · 무한 모드
- **모디파이어**: 출격 전 무작위 3개(질주하는 적 / 탄막 폭풍 / 유리 대포 / 보급 단절 / 강철 장갑 / 평온한 하늘) 중 1개를 고르거나 건너뜀. 위험을 지면 경험치·점수·크레딧·드랍 보상이 커진다. 재출격할 때마다 새로 뽑는다.
- **무한 모드**: 5스테이지 클리어 화면에서 [무한 모드 계속]. 6스테이지부터 1~5 구성을 다시 돌며 루프마다 보스 체력 +50%, 적 탄 속도 +6%, 스폰 증가. 크레딧은 이미 받은 만큼 제외하고 이어서 정산.

### 4-6. 일일 도전
타이틀의 **📅 일일 도전**: 날짜가 같으면 시드와 모디파이어가 같아서 모두가 같은 조건으로 도전한다(재도전은 같은 조건). 기록은 날짜별 저장, 그날 첫 도전은 크레딧 +25%.

### 4-7. 그 외
콤보 배율(최대 ×2.5), 그레이즈(탄 스치기) 점수/게이지, 무피격 스테이지 S랭크 보너스.

## 5. 다음에 해볼 아이디어 (우선순위순)
1. **파일럿 전용 궁극기 연출**: 파일럿마다 다른 컷인/효과 (현재는 패시브 + 기체 스킨만 구현됨).
2. **런 모디파이어(뮤테이터)**: 시작 시 저주/축복 카드 1장 (예: 적 탄 +20% 속도 ↔ XP +30%), 난이도 대신 선택형 위험·보상.
3. **융합 확장**: 현재 3종 → 6~8종 (패시브 포함 융합 예: 자동 방벽 + 드론 = 아이기스 오빗), 레시피 도감.
4. **무한 모드 / 보스 러시 / 일일 도전**(날짜 시드 고정 + 공유용 결과 카드).
5. 스테이지 기믹(운석 지대 충돌, 용암 기둥, 중력 왜곡), 보스 3페이즈.
6. 스토리 연출: 보스 등장 전 짧은 브리핑 컷(스토리 모드 대신 가벼운 서사).
7. 업적/도감, 기체 스킨, 다국어.

## 6. 설계 원칙
- 규칙은 `src/core`(순수 TS)에만 → 시뮬레이터로 수백 판 밸런스 측정(`npm run sim`).
- 모든 수치는 `data.ts`/`build.ts`/`meta.ts` 한 곳에 모은다.
- 공정함: 레이저 예고선은 고정, 보스 패턴은 읽을 수 있게, 레벨업 중 완전 정지.

## 7. 파일럿별 궁극기 (구현 완료: 언니=B안 미사일 포격, 동생=A안 시간 정지)

> 구현됨: 에이스=자매의 손바닥 / 언니=미사일 포격(3.3초, 위에서 미사일 비, 무적 2.5초) / 동생=시간 정지(2.5초, 적·탄·보스 정지, 내 피해 1.5배, 무적). 컷인은 파일럿 초상화+이름 연출(별도 컷인 일러스트가 오면 교체 가능). 아래는 설계 당시의 후보표.

지금은 세 파일럿 모두 같은 「자매의 손바닥」을 쓴다. 파일럿마다 *다른 궁극기*가 있으면 파일럿 선택이 훨씬 의미 있어진다.
공통 규칙(제안): 게이지 100%에서 발동, 컷인(1.5~2초 정지) → 효과. 컷인 카드는 파일럿 초상화 기반으로 새로 필요(`pilot_cutin_1.png`, `pilot_cutin_2.png`).

| 파일럿 | A안 (직관적) | B안 (개성 강함) | C안 (빌드 연계) |
|---|---|---|---|
| **에이스** (기본) | 기존 손바닥 그대로 | — | — |
| **언니** (공격형) | **화력 집중**: 5초간 정면에 초거대 레이저 + 연사 2배, 모든 탄 제거 | **포격 지원**: 화면 위에서 미사일 40발이 적을 추적하며 쏟아짐(미사일 레벨 연동) | **오버차지**: 5초간 모든 모듈 레벨 +1(임시), 융합 효과 활성 |
| **동생** (성장형) | **시간 정지 2.5초**: 적/탄 정지, 나만 움직이며 공격(게이지·콤보 유지) | **젬 폭풍**: 화면의 적 전멸 + 경험치 젬 대량 + 즉시 레벨업 1회 | **방벽 전개**: 8초간 무적 방벽 + 자석 최대 + 경험치 2배 |

**추천 조합**: 언니=B안(미사일 포격, 컷인이 화려하고 '미사일 타격감' 개선과 시너지), 동생=A안 시간정지 또는 B안 젬 폭풍(성장형 정체성). 고르면 컷인 이미지 프롬프트를 docs/ASSET_PROMPTS.md에 추가한다.
**구현 난이도**: 코어에 `ult.kind`와 파일럿별 효과 함수만 추가하면 되고(시뮬레이션 테스트 가능), 연출은 `UltFx`에 컷인 이미지 키만 바꿔 끼우면 된다.
**밸런스 메모**: 현재 게이지 충전은 한 판에 약 3~5회. 파일럿 궁극기가 더 강해지면 충전량을 낮춰야 한다.

## 8. 타격감 설계 메모 (미사일)
착탄 순간에 겹쳐 주는 신호: ① 적 하얗게 번쩍(8프레임) ② 뒤로 밀림(넉백 8px) ③ 충격 링 2겹 + 스파크 줄기 + 가산 섬광 ④ 화면 흔들림(처치 5 / 일반 2.5) + 처치 시 2프레임 정지 ⑤ 묵직한 효과음(저음 쿵 + 노이즈) ⑥ 범위 피해(반경 52, 절반) ⑦ 처치 시 스프라이트 폭발 + 점수 팝업.
