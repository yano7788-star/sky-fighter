## 2026-10-05 (v2.3.0) — 지상전 v2: 핫라인 마이애미식 스크롤 맵 (절충안)
- **구조 개편**: 고정 방 4개 → **옥상 → 건물 1층 → 2층 → 격납고**를 아래에서 위로 걸어 올라가는 스크롤 맵(18×132 타일, `core/groundmap.ts`). 벽·유리(탄·시야 통과)·스윙 도어(박차면 근처 적 기절)·잠긴 문(구역을 정리하면 열림)·출구(보스 격파 후). 카메라는 플레이어를 따라가며 조준 방향으로 내다본다.
- **적 AI** (`ground.ts`): 순찰/제자리 두리번 → **시야각 110°·벽에 막히는 시야**로 발견 → 반응 지연 후 교전, **총소리 반경**(권총 230·SMG 330·샷건 650·레일 450, 벽 너머 ×0.55)에 반응해 소음 지점을 조사, 길이 막히면 **거리장(BFS)** 으로 추격. 비명으로 가까운 동료 호출. 신규 적: 헤비(방패·다수 탄 흡수, 문 기절 면역)·경비견(빠름, 문 기절 면역). 시야 부채꼴을 벽에 맞춰 잘라 표시.
- **절충안 난이도**: 일반 적(보병·저격·경비견) 체력 ≈ 권총 1발, 돌격병 2발, 헤비 8. 플레이어는 체력 4칸 유지, 보스는 체력제. 죽으면 R/Enter/탭으로 **즉시 재시작**(그 구역 입구, 목숨 1개).
- **영구 잔존물**: 시체(탄 방향으로 미끄러져 바닥에 남음), 혈흔·그을음·탄흔·**탄피**(날아가 바닥에 고정, RenderTexture 데칼), 적이 **떨군 무기**(주우려면 권총/빈 총일 때 닿기, 아니면 E 줍기 — 들고 있던 총은 그 자리에 떨어짐), 던진 총. 구역을 정리하면 체력 하트가 나온다.
- **무기 효과**: 무기별 총구 화염(권총 작게/SMG 뾰족/샷건 크게/레일 청색), 탄피 360° 배출, 연기, 반동 킥·방향 흔들림, 샷건 넉백, 레일 궤적선, 벽 피탄 불꽃·탄흔, 수동 던지기(F/우클릭).
- 봇(`groundbot.ts`)은 거리장으로 길을 찾아 구역 정리 → 무기 줍기 → 문으로 올라간다. 약한 봇 클리어 ≈ 57%(사망은 보스방). 테스트 21개(총 190).
- 에셋 v2(도트 아트 우향 스프라이트) 프롬프트: docs/ASSET_PROMPTS.md §9. 새 에셋이 오면 파일럿·적 스프라이트를 조준각 회전 방식으로 교체 예정(현재는 기존 앞/뒤 스프라이트 임시 사용).

## 2026-10-04 (v2.2.0) — 지상전 「강하」 1차 구현
- **흐름**: 3스테이지 보스 격파(+유물 선택) 직후 → 격추 컷("EJECT!") → 줌인 + 모자이크(WebGL Pixelate) → 착지 컷 → **픽셀 아트 트윈스틱 탑다운 지상전** → 보스 격파 → 이륙 컷 → 줌아웃 + 번쩍임으로 본편 복귀 (보상: 점수·체력 40% 회복·유물 3택1 → 다음 스테이지 항로 선택). `?ground` 로 접속하면 시작하자마자 체험.
- **코어** `src/core/ground.ts` `GroundSim`: 룸 3개(웨이브) + 보스방. 구르기(무적 24f·쿨 66f, 에이스는 쿨 −20%), 엄폐물(탄 차단·밀어내기), 폭발 드럼통 연쇄, 무기 4종(권총/샷건/SMG/레일) + 탄 소진 시 던지기, 수류탄, 대시-킬(구르기 직후 첫 사격 ×1.5), 스타일 포인트(돌진을 구르기로 통과 → 슬로모션), 콤보 점수, 파일럿별 특성(언니 화력 ×1.2 / 동생 관통 +1·탄속 +15%). 적 6종(보병·돌격병·저격수·포탑·드론 벌떼·장갑차) + 보스 「격납고 수문장」(3페이즈, 돌진 후 약점 노출 ×1.6, 박격포 예고, 페이즈마다 보급 드랍).
- **본편 연동** `Sim.groundEnabled/groundRequest/groundActive`: 씬이 켤 때만 동작(헤드리스 시뮬레이션·테스트는 건너뜀). 빌드의 화력·연사·체력이 지상전에 반영(`groundOpts`). 지상 사망 → 목숨 1개로 이 룸 재도전, 없으면 게임오버.
- **렌더/입력** `src/scenes/GroundScene.ts`: 본편(GameScene)을 pause 하고 위에 띄움. PC: WASD + 마우스 조준·클릭 사격, Shift/Space/우클릭 구르기, Q 수류탄. 모바일: 왼쪽 스틱 이동, 오른쪽 스틱 조준+사격, 구르기·수류탄 버튼. 조준 보조 기본 ON. 일시정지/포기(T 두 번).
- **아트 파이프라인** `tools/process-ground.cjs`: 초록 크로마키 시트 → 스프라이트 분리 → 면적평균 다운스케일 → 알파 이진화 → 32색 팔레트 PNG(NEAREST). 파일럿 앞/뒤, 적 6, 보스, 소품 11, 바닥/벽 타일, 컷 3장(우하단 워터마크 크롭). 효과음 11종 추가(총기별 레이어·피치 변주).
- **측정** `npm run ground -- --seeds 100 --skill 0.7`: 약한 봇(목숨 1회 이어하기) 클리어 ≈ 64%, 평균 150초, 사망은 보스방 집중. 테스트 17개 추가(총 186).
