# 개발 로그 (최신순)

> 버전은 타이틀 왼쪽 위에 `vX.Y.Z · 커밋 · 날짜`로 표시된다(빌드 때 자동 주입). 배포: https://yano7788-star.github.io/sky-fighter/ (`main` 푸시 시 GitHub Actions).
> 밸런스 수치는 `npm run sim`(약한 봇, 사람 실력의 하한선) 기준이다 — 최근 기준선: 클리어율 약 30%, 한 판 4~5분.

## 2026-10-03 (v2.1.0 ~)
**콘텐츠**
- **일일 미션**: 날짜 시드로 3개 선정(`core/missions.ts`), 여러 판 누적(sum)/최고(max), 완료 시 크레딧 1회 + 전체 완료 보너스 +100. 타이틀 `📋 미션`, `MissionScene`, 결과 화면 표시.
- **항로 선택**: 스테이지 사이 안전 1(고요/보급) + 위험 1(위험/매복) 제안(`core/routes.ts`). 레벨업 카드 오버레이 재사용(2장 가운데 정렬). 위험 항로 보상은 점수뿐(경험치·아이템 보상은 봇 클리어율을 40%대로 올려서 제거).
- **하이퍼 모드 표시**: 발동 시 중앙 "HYPER MODE!" 배너 + 효과 설명, 막대 라벨에 남은 초, 첫 플레이 힌트, 도움말 항목.
- **신규 적 이미지 적용**: 드론/기뢰/지상 포대/운석 괴수 (`tools/process-incoming.cjs newenemies`, 3열×2행 시트 자르기).
- **배포 버전 표시**: package 버전 + 커밋 해시 + 빌드 날짜, 타이틀 좌상단 작게. 버전 2.1.0.

**기획/문서**
- 지상전 모드 기획서 `docs/GROUND_MODE.md`(강하 줌인 전환 + 트윈스틱 탑다운 + 2D 픽셀 아트 방향), 지상 에셋 프롬프트(`ASSET_PROMPTS.md` 8장).
