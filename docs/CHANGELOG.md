# 개발 로그 (최신순)

> 버전은 타이틀 왼쪽 위에 `vX.Y.Z · 커밋 · 날짜`로 표시된다(빌드 때 자동 주입). 배포: https://yano7788-star.github.io/sky-fighter/ (`main` 푸시 시 GitHub Actions).
> 밸런스 수치는 `npm run sim`(약한 봇, 사람 실력의 하한선) 기준이다 — 최근 기준선: 클리어율 약 30%, 한 판 4~5분.

## 2026-10-09 (v2.10.0) — 침입 경보: 소란이 나면 경비병이 몰려온다 (구출 임무)
- **경보**: 구출 임무에서 적이 플레이어를 발견·피격·소음으로 깨어나는 순간 전역 경보(`GroundSim.alarm`, `raiseAlarm`) — 같은 구역 전원 경계 + 사이렌/붉은 맥동 + 약 5초마다 경비병 무리가 증원(3·3·4·4·5명, 3·5번째는 헤비 포함, 총 19명). 증원 지점은 구역별 가장자리(`Level.reinforce`)에서 플레이어에게서 멀고 안 보이는 곳을 골라 플레이어 쪽을 보고 나타난다.
- 소음기 권총은 한 방에 못 죽이므로(보병 60·돌격 100·저격 60·헤비 260 vs 30) 쏴서 처치하는 순간 들켜 경보 → **암살·시선 끌기·연막/섬광**이 사실상 필수. 암살·시선 끌기는 경보를 울리지 않는다(찌르는 동안 적은 얼어붙음).
- 구출 전 사망 후 재도전하면 경보 해제(증원병 제거). 인질을 풀 때 이미 경보 중이면 증원 무리가 즉시 한 번 더. HUD/브리핑 문구 갱신. 테스트 232개.
