## 1. 핵심 경험 (한 줄 요약)
**"격추 → 추락 → 확대되는 지상 → 총을 들고 살아남아 격납고의 기체를 되찾아 이륙"** — 약 90~150초의 짧은 스테이지.

- 공중전: 가로 450 논리 해상도를 넓게 보는 **조망 시점** (지금의 게임).
- 지상전: 같은 해상도지만 **월드 스케일이 1.8~2.2배로 확대**돼 캐릭터가 크게 보이는 **탑다운 트윈스틱**.
- 전환 연출이 이 모드의 핵심 재미 — 카메라가 한 번에 "확 가까워지는" 순간을 가장 공들여 만든다.

## 2. 전환 연출 (Zoom-in Descent) — 최우선 구현 대상
| 단계 | 시간 | 연출 |
|---|---|---|
| ① 격추 | 1.0s | 보스 특수 공격/스토리 피격 → 기체 불꽃·흔들림, 슬로모션(기존 `slowmo` 이벤트 재사용), 컷인 "EJECT!" |
| ② 추락 | 1.5s | 기체 이탈 → 낙하산/사출 파티클, 배경 구름 층이 **빠르게 위로 흐르며 확대**(패럴랙스 속도 ↑, 스케일 1.0→1.6) |
| ③ 강하 줌 | 1.2s | `world` 컨테이너 scale 1.0→2.0 트윈(`Cubic.easeIn`) + 비네팅·모션 블러 느낌의 속도선, 구름이 눈앞을 스쳐 지나감 → 하얀 플래시 |
| ④ 착지 | 0.8s | 화면 흔들림(10) + 먼지 링, 지상 타일 배경 페이드인, 캐릭터 착지 포즈, HUD가 지상용으로 교체 |
| ⑤ (복귀) 이륙 | 2.0s | 기체 탑승 → 반대로 **줌아웃 + 상승**, 구름 위로 올라가 공중전 HUD 복귀 |

**구현 방식**: 한 씬(`GameScene`) 안에서 `world` 컨테이너의 scale·오프셋을 트윈하고, 배경 레이어를 *하늘(스크롤)* ↔ *지상 타일맵*으로 크로스페이드.
씬을 갈아끼우지 않으므로 빌드·XP·유물·점수가 그대로 이어진다. (지상 규칙은 `core/ground.ts`, 렌더는 `render/ground.ts`)

## 3. 지상전 규칙 (트윈스틱 탑다운)

### 3-1. 조작
- **PC**: WASD 이동 + 마우스 조준/클릭 사격 (또는 방향키 이동 + Space 자동 조준 사격). Shift/우클릭 = **구르기**, Q = 수류탄, E = 상호작용(격납고/상자).
- **모바일(트윈스틱)**: 왼쪽 가상 스틱 = 이동, 오른쪽 가상 스틱 = 조준+발사(당기고 있으면 사격). 오른쪽 아래 버튼: 구르기. 기존 "드래그 이동 + 자동 발사"와의 혼란을 막기 위해 지상 모드 진입 시 튜토리얼 말풍선 1회.
- **조준 보조(Aim Assist)**: 설정에서 켜면 조준 방향 ±12° 안의 적에 약한 흡착 — 모바일 기본 ON.
- 게임패드: 왼 스틱 이동, 오른 스틱 조준·사격(자동), RB 구르기, LB 수류탄.

### 3-2. 캐릭터
- 선택한 **파일럿(에이스/언니/동생)** 이 그대로 주인공. 파일럿별 지상 특성:
  - 에이스: 균형형. 구르기 쿨다운 짧음.
  - 언니(공격형): 샷건형 근접 폭발력, 체력 약간 낮음.
  - 동생(성장형): 장거리 정밀 사격 + 지상 XP 획득 +20%.
- 체력은 공중 에너지와 **별도 게이지(하트 4칸)** — 지상에서 죽으면 "기체를 못 찾고 포로" 대신 **목숨 1개 소모 후 체크포인트 재시작**(없으면 게임오버). 공중과 같은 목숨 풀을 쓴다.

### 3-3. 전투 핵심 (재미의 설계)
1. **구르기(Dodge Roll)**: 0.35초 무적 + 이동. 쿨다운 1.2초. 탄 사이를 구르는 타이밍이 핵심 스킬.
2. **엄폐물**: 낮은 벽/상자/기둥에는 탄이 막힘(플레이어·적 모두). 일부는 파괴 가능(폭발 드럼통 = 연쇄 폭발 수단).
3. **대시-킬 콤보**: 구르기 직후 첫 사격은 피해 ×1.5, 연속 처치 시 콤보 배율(공중과 같은 `comboMultiplier`) → 공중↔지상 점수 일관.
4. **탄 반사(블록 & 패리)**: 근접 적의 돌진을 구르기 무적으로 통과하면 "스타일 포인트"+슬로모션 0.15s (핫라인 마이애미식 짜릿함).
5. **무기 4종 + 줍기**: 권총(무한, 기본) / 샷건 / SMG / 레일 라이플. 적이 떨군 무기를 줍고, 탄이 떨어지면 **던져서 피해**(엔터 더 건전 오마주). 모듈/유물은 지상에서도 적용(예: 연사 가속, 화력 증폭, 연쇄 폭발).
6. **XP/카드**: 지상에서 적을 잡으면 같은 XP 젬 → 레벨업 카드(같은 풀 중 지상 호환 카드만 제안: 연사/화력/방벽/흡수 등). 공중 전용(드론·미사일·레이저)은 지상 변환 규칙으로 호환(드론=자동 사격 포탑 위성, 미사일=수류탄 자동 추가 등).

### 3-4. 적 구성 (지상)
| 적 | 행동 | 비고 |
|---|---|---|
| 보병(소총) | 엄폐하며 3점사 조준 사격 | 기본 |
| 돌격병 | 구르기로 피해야 하는 돌진 | 근접 위험 |
| 저격수 | 레이저 조준선 예고 후 단발 | 공중 레이저 예고 UX 재사용 |
| 포탑 | 고정, 회전하며 부채꼴 탄막 | 공중 포대(`enemy_turret`)의 지상 버전 |
| 드론(공중→지상) | 벌떼로 몰려옴(인해전술 재사용) | 공중의 벌떼와 세계관 연결 |
| 장갑차(미니보스) | 기관포+박격포 예고 원형 | 룸 클리어 보상 |
| **지상 보스: 격납고 수문장** | 3페이즈(탄막→돌진→포격), 약점 노출 규칙 재사용 | 처치 시 기체 확보 |

### 3-5. 스테이지 구조 — "3 룸 + 보스"
룸 단위(화면 1~2개 크기) 아레나를 연속 돌파한다. 각 룸은 웨이브 2~3회 → 문 개방. 데드엔드 없이 한 방향으로 진행해 모바일에서도 길을 잃지 않는다.
1. 룸 1 (착지 지점): 튜토리얼성 — 보병 3 + 엄폐물 학습.
2. 룸 2: 돌격병/포탑 혼합, 폭발 드럼통 활용 유도.
3. 룸 3: 저격수 + 벌떼 웨이브, 무기 상자(선택 보상).
4. 격납고 보스전 → 기체 시동 컷 → **이륙 줌아웃** → 공중전 복귀.
- 목표 시간: 룸당 25~35초, 보스 30~40초 → **총 100~150초**. 길어지면 슈팅 본편의 호흡이 깨진다.

### 3-6. 보상/연결
- 지상 클리어: 유물 1개(3택1, 지상 전용 후보 3종 포함) + 크레딧 보너스 + 업적 연동.
- 공중전 복귀 시 **새 기체 외형(스킨)** 으로 이륙 — 시각적 보상(스킨 이미지 필요, 선택).
- 한 판에 지상전은 **1~2회**: 3스테이지 보스 직후(첫 번째), 5스테이지 진입 전(두 번째, 무한 모드에서는 5스테이지 주기).

## 4. 시스템 설계 (코드 구조)
- `src/core/ground.ts` (순수 TS): `GroundSim` — 위치/속도/구르기/탄/적/엄폐물/룸 진행. 같은 시드 → 같은 결과. 기존 `Sim`이 `mode: 'AIR' | 'DESCENT' | 'GROUND' | 'ASCENT'`를 가지고 틱을 위임(`step` 안에서 모드 분기). 레벨업/유물/XP/콤보/점수는 `Sim`이 소유(공통).
- `src/core/data.ts`: `GROUND` 상수(구르기 시간, 무기표, 적 스탯, 룸 구성표).
- `src/render/ground.ts`: 지상 타일 스크롤/룸 렌더, 캐릭터·적 스프라이트, 조준선, 엄폐물, 데칼(탄흔·피), 줌 트윈 연출.
- `src/scenes/GameScene.ts`: 모드별 입력 라우팅(공중 드래그 ↔ 지상 트윈스틱), 줌 전환 연출 타임라인.
- `tools/sim-run.ts`: 지상 봇(엄폐 이동 + 가까운 적 조준) 추가로 룸 클리어율·피해량 측정.
- 테스트(Vitest): 구르기 무적 프레임, 엄폐물 탄 차단, 룸 진행/문 개방, 모드 전환 시 빌드·점수 유지, 지상 사망→목숨 소모.

## 6. 위험 요소와 대응
- **조작 혼란(모바일)**: 지상 진입 시 명확한 튜토리얼 + 첫 룸은 적 3기로 조작 학습. 조준 보조 기본 ON.
- **분량 폭증**: 룸 3 + 보스 1로 고정. 무기 4종·적 6종 이상 늘리지 않는다.
- **슈팅 본편 호흡**: 지상전 100~150초 상한, 1~2회만 등장. 스킵 옵션은 두지 않되 클리어 보상이 충분하게.
- **성능**: 지상 타일은 2~3장 반복 타일 + 데칼 최대 80개, 적 탄 상한은 공중과 동일 규칙.
- **세계관**: "격추 → 지상 기지 침투 → 기체 탈환"이 단순해서 컷 3장(격추/착지/탑승)으로 충분.

## 7. 필요한 이미지 (프롬프트는 `docs/ASSET_PROMPTS.md` 8장)
최소 구성(M3까지): ① 파일럿 탑다운 캐릭터 3종(에이스/언니/동생, 8방향 대신 **4방향 + 회전**으로 단순화) ② 지상 적 6종 ③ 지상 타일 3종(바닥/벽/엄폐물) + 소품 ④ 격납고 보스 ⑤ 격추·착지·탑승 컷 3장. 한 장씩 뽑기보다 **스프라이트 시트(그리드)** 로 뽑는 것을 권장하되, 이전처럼 배경이 섞이지 않도록 프롬프트에 "no scenery" 명시.

## 8. 아트 방향: 지상전은 2D 픽셀 아트 (제안 → 채택 후보)
**의도적 화풍 전환**: 공중전(세미리얼 일러스트) → 강하하는 순간 화면이 **모자이크처럼 픽셀화**되며 16비트풍 지상으로 전환("지상 세계로 들어간다"는 전환 연출과 화풍 변화를 하나로 묶음).
- **장점**: 작은 해상도라 캐릭터·탄이 또렷함, 생성/제작 비용이 낮음(32×32급), 핫라인 마이애미·건전 느낌, 화풍 대비로 모드 전환이 확실히 체감됨.
- **단점**: 생성형 AI는 "진짜 픽셀 격자" 일관성이 약함 → **제작 파이프라인으로 해결**: 기존처럼 생성한 탑다운 스프라이트를 `tools/process-incoming.cjs pixelize`로 *다운스케일(최근접) + 팔레트 양자화(24색)* 해서 일관된 픽셀 아트로 변환(타일은 32×32 반복, 캐릭터 32×32, 보스 96×96). 에셋 프롬프트는 8장 그대로 사용 가능("clean flat shapes, strong silhouette, limited palette"를 덧붙이면 변환 품질↑).
- **렌더**: 지상 레이어만 `NEAREST` 필터 + 정수 배율(×3), 캐릭터 이동은 서브픽셀 허용·스프라이트는 픽셀 스냅. 전환 연출에 픽셀화 단계(모자이크 블록 크기 1→12→3으로 변하는 셰이더/RenderTexture 다운샘플) 추가.
- **대안**: 외주/에셋 팩(itch.io) 구매는 라이선스 확인 필요, 직접 도트 제작(Aseprite/PixelLab류)은 품질↑·시간↑.
